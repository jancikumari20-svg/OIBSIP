This repository contains my task submissions for the Oasis Infobyte Data Science internship. Each task has its own folder with the notebook, a README and output screenshots.

Tasks

Task 2: Unemployment Analysis with Python (folder DataScience-Task2-UnemploymentAnalysis)

Task 3: Car Price Prediction with Machine Learning (folder DataScience-Task3-CarPricePrediction)

Task 4: Spam Detection with Machine Learning (folder DataScience-Task4-SpamDetection)

Task 5: Sales Prediction Using Python (folder DataScience-Task5-SalesPrediction)

Tools used

Python, pandas, numpy, matplotlib, seaborn, scikit-learn, NLTK and Jupyter Notebook (Google Colab).
